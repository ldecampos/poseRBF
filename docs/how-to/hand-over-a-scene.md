# Hand over a scene

An RBF is kept whole in the scene: its graph, its poses and its options.

| To...                  | Is needed                                |
| ---------------------- | ---------------------------------------- |
| Open, play and animate | Maya 2025 to 2027, Bifrost 2.14 or later |
| Edit the RBF           | The above, and poseRBF                   |

- **Older Maya:** a scene saved by a newer Maya does not open in an older one. Save with
    the oldest one in use.
- **Older Bifrost:** the same. An RBF made with Bifrost 2.14 opens in every later one.
- **Referencing:** the RBF comes with the file. Edit it in the file that holds it.
